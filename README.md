# SurvivalIa

Guia de sobrevivência com IA que roda inteiro no celular, **sem internet**: água, fogo, plantas do Brasil e emergência, com cada frase tirada de fonte oficial.

Este repositório só guarda os instaladores. O código-fonte é privado.

## Baixar

**Versão atual: 0.1.4** → [SurvivalIa-0.1.4.apk](https://github.com/bkhenrique/survival-ia-apk/releases/download/v0.1.4/SurvivalIa-0.1.4.apk)

Todas as versões: [Releases](https://github.com/bkhenrique/survival-ia-apk/releases)

## Instalar no Android

1. Baixe o arquivo `.apk` no celular (Android 7 ou mais novo, 64 bits).
2. Abra o arquivo e permita "instalar apps desta fonte" quando o Android pedir.
3. Abra o SurvivalIa. A biblioteca e a emergência já funcionam; a IA é opcional e baixada dentro do app.

Para conferir o arquivo, compare o SHA-256 com o `.sha256` da mesma versão.

## Aviso

Material educativo. Não substitui atendimento médico nem socorro profissional. Em emergência com sinal, ligue primeiro para o número de emergência local.
